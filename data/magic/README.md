# data/magic/

Dono: **Ludimus**.

- `spells.json` — magias: círculo, mana, reagentes, alvo, efeito
  e palavras de poder.
- `reagents.json` — reagentes, no mesmo formato de item, com
  `type: "reagent"`.

Os nomes das magias e as palavras de poder são nossos. Não copiar
os do Ultima Online. O esquema está em `docs/DATA_SCHEMA.md`.
