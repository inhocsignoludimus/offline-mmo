# art/src/wip/

Isto **não** é arte de runtime. A engine não lê esta pasta.

`paperdoll_weapons_batch1/` guarda o fechamento incompleto de sete armas do paperdoll (`shortsword`, `dagger`, `hand_axe`, `mace`, `longbow`, `staff`, `wand`), com fontes Blender, PNGs de cabo inteiro e referências de mão aberta. A empunhadura convincente não existe: falta patch de mão fechada para pele, luva de couro, malha e placa, e uma máscara que apague a palma aberta. A máscara sozinha não cria dedos.

Não copiar estes PNGs para `art/paperdoll/`. O broquel publicado está fora daqui, em `art/paperdoll/{m,f}/buckler_fixed.png`.
